What changed

1.0.7: everything since 1.0.4.

One release, three new systems, and the desktop polish that came with them.

01New

Local models, without a provider key

Browse Hugging Face from inside the app, score every quant against this machine's VRAM, install a llama.cpp runtime and serve the model straight into the chat picker. Downloads resume; gated repos are refused with a reason instead of a mystery failure.

02New

Usage without invented quotas

A Usage & limits view that separates what the provider reports, what the gateway sends, and what this app counted. NVIDIA NIM exposes no quota API, so it says Not exposed, never a made-up percentage. A 429 becomes a classified, timed state with a live countdown when a reset is supplied.

03Updated

Skills that stay current

Background checks compare installed GitHub skills with their source repositories and flag what changed, with one Update all. Disabling a skill moves it out of the CLI's view instead of deleting it, and inline delivery covers models without native skill support.

The app

A real agent, in a real window.

Not a chat wrapper. One long-lived fcc-claude process per conversation, rendered properly.

Sessions that survive

Follow-ups reuse the running agent; reopening a conversation resumes the stored session. Conversations, tool state and usage are written atomically as JSON, so a crash never leaves a half-written file.

Tool calls you can read

Streaming text, thinking with duration, expandable tool cards with input and output, per-turn tokens and cost, permission denials. Stop mid-turn and the partial answer is kept and marked stopped.

Files that reach the agent

Native pickers and drag-and-drop onto the composer. Images get thumbnails; attachment directories are passed as --add-dir, so the agent can actually open what you sent.

Skills, managed natively

Discover across skills.sh, GitHub and curated collections; inspect the real SKILL.md and safety findings before installing. Project or global scope, categories, manual-only mode, and no npx dependency.

Your server, respected

Connect to an FCC server you already run, or let the app start one. It only ever stops a server it started itself; an external server is reported as external and left alone.

Local by default

No telemetry, no analytics, no remote storage. The proxy token is encrypted through the OS keystore (DPAPI on Windows), and monitoring reads FCC metadata without ever sending a model request.

Before you install

  1. 1
    Install Free Claude Code. FCC Desktop is a client; it needs fcc-server and fcc-claude.
  2. 2
    Start the server. The default endpoint is 127.0.0.1:8082; the app can auto-start it for you.
  3. 3
    Add a provider key in FCC's Admin UI, or download a local GGUF model and skip keys entirely.

Setup instructions, troubleshooting and verified behaviour live in the repository README.
